# Tệp sơ đồ lưu trữ

Thư mục này chứa các sơ đồ cũ hoặc định dạng xuất dư thừa, được chuyển ra khỏi
thư mục `docs` chính để tránh nhầm lẫn khi biên soạn báo cáo.

Các nhóm đã lưu trữ:

- sơ đồ use case tổng hợp cũ trước khi tách theo từng nhóm tác nhân;
- phiên bản sơ đồ quản trị viên cũ;
- activity diagram thử nghiệm gộp UC18, UC09 và UC19;
- các ảnh PNG trùng với phiên bản SVG đang được sử dụng.

Các tệp này không được xem là phiên bản hiện hành của báo cáo.
